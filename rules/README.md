# Rules and their enforcers
Every rule names what enforces it. "ADVICE" means only prose holds it; a repeated mistake under an ADVICE rule must be promoted to a higher enforcer in the same change (`docs/change-proposals.md`). Leak classes are in `rules/leak-classes.md` (C1 to C11).

Status: **enforced** = a tool refuses the wrong action; **partly** = a tool or template catches some cases, a person catches the rest; **advice** = prose only. "Reference gate" means the merge gate of the first project that ran on these rules; the framework's own gate tool arrives in F2, so until a project pins it, gate rows hold only where that project's gate does. A "reference gate"/CI row is also capped at detective, not preventive, enforcement on a private repo under a free GitHub plan: real blocking needs branch protection, which needs a public repo or a paid plan - confirmed unavailable (403, "Upgrade to GitHub Pro or make this repository public") on every repo checked, 2026-10-15. `templates/gate-audit.yml` (required per `adapters/README.md`) is the detective equivalent: it cannot stop a bypass, only open an issue within minutes of one happening.
